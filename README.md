# Personal Portfolio

## Project Overview

A handcrafted, production-ready portfolio site for Me, a Computer Science undergraduate passionate about full-stack development, AI/ML, and open-source contributions.

The portfolio showcases my skills, projects, certifications, experience, and social profiles through a modern, responsive, and interactive user interface.

## Live Demo

🌐 **Live Portfolio:**
https://my-portfolio-main-1-q8zk.onrender.com/

💻 **GitHub Repository:**
https://github.com/Adithya-vel/My-Portfolio-main

## Features

* **Responsive design** with premium glassmorphism cards and subtle micro-animations
* **Theme switching** (Indigo, Aurora, Ember, Light) persisted via `localStorage`
* **Smooth scroll animations** and scroll-progress indicator
* **Animated gradient background** and floating blurred blobs for visual flair
* **Interactive project cards** with hover lift and transition effects
* **Accessible, semantic HTML** with improved typography using Google Fonts
* **Contact section** with email and social links
* **Section navigation** with animated navbar
* **Performance-optimized build** using Vite and Tailwind CSS
* **Responsive layout** optimized for desktop and mobile devices

## Tech Stack

* **React** (TypeScript)
* **Vite** – fast development server and bundler
* **Tailwind CSS** – utility-first styling
* **Framer Motion** – animations and transitions
* **Lucide React** – icon library
* **Google Fonts** – Inter, Outfit, JetBrains Mono
* **Git & GitHub** – version control
* **Render** – frontend and backend deployment
* **MongoDB** – database for the URL Shortener backend
* **Express.js** – backend API for the URL Shortener

## Installation

### Clone the Repository

```bash
git clone https://github.com/Adithya-vel/My-Portfolio-main.git
```

### Change into the Project Directory

```bash
cd My-Portfolio-main
```

### Install Dependencies

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

Open the URL shown in the terminal, usually:

```text
http://localhost:5173
```

## Production Build

To create a production build:

```bash
npm run build
```

The generated production files will be available inside the `dist/` folder.

## Folder Structure

```text
src/
 ├─ assets/          # Images, icons, and static assets
 ├─ components/      # Reusable UI components
 │   ├─ layout/      # Navbar, Footer, etc.
 │   ├─ sections/    # Hero, About, Skills, Projects, etc.
 │   └─ ui/          # Reusable UI components
 ├─ constants/       # Portfolio data
 ├─ hooks/           # Custom React hooks
 ├─ pages/           # Page components
 ├─ App.tsx          # Root component
 └─ main.tsx         # Application entry point
```

## Deployment

The portfolio frontend is deployed as a **Render Static Site**.

### Frontend

**Platform:** Render
**Build Command:**

```bash
npm run build
```

**Publish Directory:**

```text
dist
```

**Live URL:**

https://my-portfolio-main-1-q8zk.onrender.com/

### Backend

The URL Shortener backend is deployed separately as a **Render Web Service** using:

* Node.js
* Express.js
* MongoDB
* JWT Authentication

The backend uses environment variables configured securely through Render and does not expose sensitive credentials in the GitHub repository.

## Project Highlights

### URL Shortener

A full-stack URL shortening service featuring:

* JWT authentication
* MongoDB persistence
* Protected URL management
* Click tracking
* Short URL generation
* Express.js REST APIs
* Production deployment

## Security

Sensitive environment variables such as database credentials and authentication secrets are stored securely in the deployment environment and are **not committed to GitHub**.

The `.env` file is excluded from version control using `.gitignore`.

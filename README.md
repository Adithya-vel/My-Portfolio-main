# Personal Portfolio

A simple personal portfolio website built using React and Tailwind CSS.

## Features

- Responsive design
- Modern UI
- About Me section
- Skills
- Projects
- Certifications
- Contact section
- Smooth scrolling and basic animations

## Tech Stack

- React
- Vite
- Tailwind CSS

## Getting Started

1. Clone the repository

```bash
git clone <repository-url>
```

2. Install dependencies

```bash
npm install
```

3. Start the development server

```bash
npm run dev
```

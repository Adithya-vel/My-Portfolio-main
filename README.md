# Adithya Vel M Portfolio

Create a premium, modern, highly interactive personal developer portfolio website using React + Tailwind CSS.

IMPORTANT:

Do NOT include any default developer illustration, cartoon character, stock person, avatar, AI-generated human, or placeholder profile image. Leave the hero image area empty or use a clean abstract gradient/shape as a placeholder. I will replace it later with my own image.

Design Style:

- Apple-inspired minimalism

- Modern SaaS aesthetic

- Dark theme

- Glassmorphism

- Blue, Indigo and Purple gradient accents

- Premium typography

- Soft shadows

- Large spacing

- Pixel-perfect alignment

- Elegant and professional
